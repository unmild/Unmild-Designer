Why Unmild Designer exists

Unmild Designer exists to make the PCB workflow more deliberate: create the layout, review it visually, check what can be checked today, and release manufacturing data with its scope made clear.

The PCB canvas is built for direct work: place components, route traces, shape the board outline, use grid snapping and live coordinates, and adapt the interface with custom navigation, colors, shortcut keys, and dockable or floating panels.

When the layout needs a different perspective, 3D verification renders the current board for visual review. The Run view adds visible behavior, readings, and problem feedback for supported components, while the Simulation workbench provides transparent DC, AC, and transient RC analysis.

Unmild Designer also includes a first-pass microstrip and differential impedance calculator, a schematic-intent and basic ERC foundation, and a Verification workbench that brings basic PCB DRC and ERC results together.

For release, the basic DRC gate precedes Gerber X2 and Excellon output, review drawings, and a release manifest. The product does not present a preview as a certified manufacturing format: IPC-2581 is labeled as a geometry preview and ODB++ is not generated until the underlying design data can support it safely.

Product-first EDA software

PCB design · 3D verification · circuit behavior

Unmild Designer is written in Rust and independently developed from the ground up as a focused desktop workspace for taking boards from layout to fabrication.

Named in Sanskrit, on purpose

A few of Unmild Designer's own tools and file formats borrow their names from Sanskrit rather than the usual EDA-software vocabulary.

.tamas
darkness / dark energy

The project file extension. Every board is saved as a single .tamas file inside its project folder.

Setu
bridge / connector

The wire tool — the thing that bridges one pad to another with a copper trace.

Saad
to call / to summon

The parts picker, also labeled Summon in the toolbox — call up a component and drop it on the board.
